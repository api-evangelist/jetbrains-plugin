  <h2>2025.2</h2>
  <ul>
    <li><b>Project rules</b> – Guide AI with coding standards and tech stack, shared across your team.</li>
    <li><b>Attach images in the chat</b> (for Anthropic and OpenAI models).</li>
    <li><b>New file types supported for code completion</b> – The list of supported file types now includes SQL, YAML, JSON, Markdown, and more.</li>
    <li><b>Local multiline completion</b> is now available for Java and C++.</li>
    <li><b>Choose your preferred local models for code completion</b> – Connect models like Qwen2.5, Codestral, or the open-source Mellum.</li>
    <li><b>Context improvements</b> – Add folders, reference the project structure, and attach images in the chat (for Anthropic models).</li>
    <li><b>Updated model selector</b> – Auto model selection in chat based on performance and cost. Visual cues indicating models' cost, reasoning strength, and experimental status.</li>
    <li><b>Auto-imports in Edit mode</b> – missing imports are added automatically after code changes are applied.</li>
    <li><b>Card verification for the Free tier</b> – This is required for some Free and Trial users to prevent abuse (no charges).</li>
  </ul>
